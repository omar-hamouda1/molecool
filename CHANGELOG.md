## [1.0.0a1] - 2026-09-25

### Added
- Initial alpha release of molecool.
- `calculate_distance` function for computing distance between two points.
- `calculate_angle` function for computing angle between three points.
- `build_bond_list` function for identifying bonds in a molecule.
- Type hints for all public functions.
- Unit tests for `measure` and `molecule` modules.
- Sphinx documentation.
- GitHub Actions CI workflow.
